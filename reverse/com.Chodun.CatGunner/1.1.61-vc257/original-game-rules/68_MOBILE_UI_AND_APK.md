# 68 剩余静态 UI 与 Android 试玩包

目标为手机提取的 `com.Chodun.CatGunner 1.1.61 vc257 ARM64`，工作 Unity `6000.4.10f1`。旧 XAPK 不参与。用户授权本轮继续 UI、教程、特效并提供手机安装包；已有本地广告和支付模拟保留，与正式商店交易/线上账号无关。

冻结 Main.unity 与 I2Languages.asset 的剩余 300 个静态 TMP primary term 绑定、157 个词条、14 个语言原值。当前客户端实际可接通259处；41处缺失的云端/系统/信息等页面按路径登记，不构造空壳。动态目录/参数文本、原文缺失项、外部服务保持独立。没有把原始导出的 TMP 预览文字当成正确翻译；基线0/1发现俄罗斯语首购数字标签。Resource 保留原始 Values，显式换行和原中文字体材质仍为已有本地显示适配，不是完整 I2。

团战队友锁定提示的原路径包含两个同名 Image 父节点，Transform.Find 只命中没有目标文字的一支。实际 GPU 发现韩文残留并新增0/1基线确认。接线枚举相同路径名字和原叶节点同名序号，仅唯一目标才绑定；没有重命名或保存原场景。

新手五步和首次合成手势保持已有原控制器，独立存档回归实际升级/挑战自然射击/购买/拖拽装备、合成与关闭重开/冷重载。合成旧测试首次4/5把“合成后的普通武器+原首合成临时广告武器”当成两件普通武器；只修正测试为分别断言普通1件与广告1件，没有删除合法临时武器或改变合成逻辑。

FX维持原纸币、矿石尘土、史莱姆 ParticleSystem/贴图/发射参数与已记录兼容 Shader；本轮检查发射、暂停、清除和支持的材质，并回归自然射击飘字、击败树木5/15纸币粒子和不重复入账。暂停测试首次在写TimeScale当帧立即记录时间，受到本帧模拟延迟；等待一帧后整批重跑。不是恢复全部编译原 Shader/DOTween/ParticleImage SDK。所有最终 GPU 必须实际查看。

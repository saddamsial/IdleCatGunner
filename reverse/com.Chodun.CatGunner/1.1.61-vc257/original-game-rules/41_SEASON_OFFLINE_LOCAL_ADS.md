# 41 赛季重置、离线模拟、挑战材质与本地广告

目标仅为 com.Chodun.CatGunner 1.1.61 vc257 ARM64；原 Unity 6000.0.61f1，工作 Editor 6000.4.10f1。错误 XAPK 无参与。输入哈希和本轮范围见 reports/playtest-fixes-contract.json，静态证据见 reports/playtest-fixes-native-evidence.json。三个原生导出批次分别为 52、31、41 个业务方法，各自另含 6 个异常辅助；所有条目反编译完成并核对首 16 字节和方法边界。方法数量不表示全游戏恢复比例。

## 试玩问题

70 是原 DailyCheck 第一日普通签到奖励，不是恢复客户端的新建钱包初值；新建独立钱包为 0，教程还有独立的钻石补足流程。旧试玩余额必须原样保留。100 钻石普通抽取仍需余额和库存空格；成功扣 100、增加一次抽取统计、生成普通武器并保存。原余额不足分支仅播放 SFX5。本轮复用已有 Alert 显示“钻石不足，需要 100 钻石”或满库存提示，是明确的本地体验补充，并非声称还原作者的这一段文案。

速通是奖励 30 钻石的挑战。其地面/树木/血条及 Boss 地面、怪物粒子使用的 URP 材质在当前 Built-in 工程不兼容。本轮通过 Editor API 换用已有地面平铺、健康填充、粒子兼容着色器与 Unity 内置 sprite/unlit 材质，保留原纹理、UV 平铺、颜色和粒子混合参数。四类地图共检查 1406 个 renderer、修复 578 处引用，剩余不支持材质 0。原始材质字节不变。此为渲染适配，不能当作原 URP 光照/商业效果的逐像素恢复。

## 赛季与原界面

原 Season_Reset 条件增加季号，Gun_Season 和 is_SeasonStart 设为 true；等级/经验归零，结束时间为当前时间 AddMonths(1)，VIP/Luxury 标记清除，25 项普通和高级轨领取标志及每日 23 项两轨领取标志清除，四种每日计数归零、每日日期刷新。首季启动保持季号 0；过期自动换季增加一次，重复刷新不再次增加。过期以结束日期的午夜为边界。手动 NewSeason_Start 可在当前赛季未过期时重置；原等级大于 24 的按钮先打开确认，确认后关闭两个原弹窗，停止旧滚动、滚动位置归零并保存。

原 Mission_UI 恢复结束日期“Next Season : {0}”和到下一本地午夜的 hh:mm:ss；页面开启和倒计时刷新时同步每日任务，关闭停止刷新。原每帧刷新改为本地每秒一次。服务器可信时间以明确的本机时钟替代，VIP/Luxury 商业结算不接入。

## 离线

原 OfflineProgressManager 的序列化基础上限为 28800 秒，遗物 Offline 数值以分钟乘 60 增加上限。LastSaveTime 至少离开 30 秒才结算；无效、未来时间和不足 30 秒不发奖励。使用已恢复的升级/关卡/武器缓存、选中武器种类与原常量：普通树数 clamp(stage*10+30,30,100)*(level+1)，阶段健康倍率 1/1.8/3、Boss 健康 35、金币倍率 1/1.8/3/Boss100。五波概率数组及其 metadata FieldRVA blob 的 SHA256 已直接核对；最后一波是 0/15/85/0，不以人工外推替代。

模拟使用原刷钱速率、全关卡费用时间 1.3*clearTime+5、升级可支付优先规则和部分剩余时间刷钱；只在历史最高进度内推进，到达最高进度继续刷当前关卡。超过 180 秒的清关结果为 Infinity，但保留刷钱速率。Boss 波、武器多目标数、遍历时间和已恢复的重生/皮肤/鱼类/宠物/遗物加成参与计算。原离线只把已存 Is_Buff_Pack 作为四倍系数，不授予新的购买标记。原 ApplyToManagers 不增加任务击树/通关计数，本地实现同样不伪造这些任务进度。

原 Offline 分支恢复 44 个实际对象（源切片另含 2 个祖先）、原 TMP/关闭按钮与结算布局。显示离开时间、前后关卡、三项等级及原钱包字段；原钱包字段的可见性保持资产设置。结算后立即刷新 HUD 和钱包并提交新的时间戳，立即冷重载不会再次结算。LastSaveTime 在本地 5 秒自动保存/暂停/退出路径持久化；离线结算在正常启动流程中执行，当前不声称恢复原完整后台/可信时间调度。

数字采用独立 DecimalAmount/浮点比例转换，不能声称所有原 InfVal 精度、舍入及极大值路径等价。模拟分帧预算改为 4ms，并为极小进度加 0.0001 秒保护；这两项属于本地运行适配，原帧预算/零进度行为保持在原生证据中。

## 用户授权的本地广告变体

用户明确要求 Editor 与后续离线包直接模拟观看成功。RecoveryForestClient.OfflineRewardedAdSimulation 默认 true，RecoveryRewardedAds 在下一帧完成回调；请求前及完成时重检门禁、Busy 防止连点，显式取消、场景关闭或模拟组件停用不奖励。成功后保存。没有广告 SDK、网络请求、生产权益或购买标记。

本轮接入的奖励入口：

- 速通：基础 30 后额外 90；Boss：基础 150 后额外 300。
- 矿场：基础 Reward_Value 后额外 3 倍；怪物：额外 PetCoin_Accum。
- 每日武器：历史进度 >29、当天未领、库存有空格，生成原 5..9 号武器，不消耗钻石或普通抽取次数。
- 每日宠物：怪物进度 Wave>0 或 Lv>0、当天未领、库存有空格，获得 1 阶宠物。
- 鱼类：前三次普通免费，第 4/5 次本地广告，每日共 5 次并保留容量门禁。
- 普通季票广告档：保留等级/领取顺序/库存门禁，经本地完成回调才能领取一次；高级付费轨仍独立。
- 团战：每天额外一次广告入场，不占两次普通额度，不开放 IAP 入场。广告入口显示时隐藏重叠的次数不足按钮。
- 探险：最高已解锁且进行中的派遣，每次开始时间减 30 分钟，每日最多两次。五个原按钮曾没有回调，已通过 Editor API 绑定原 row.AD_Reduce_onClick。

真实广告和用户授权本地模拟是不同证据层。自动升级广告、三项短时 Buff、增强重生、临时广告武器、扫荡及剩余商业页面仍待继续恢复，不能将本轮已接通入口说成全部广告已恢复。WeeklyShop 购买/排行/登录/云档/IAP、完整 I2/剩余教程 HUD/商业效果和原遗物缺表索引 300 也不以模拟成功冒充恢复。

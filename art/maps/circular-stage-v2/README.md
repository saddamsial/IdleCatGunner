# 紧凑圆形雪地、围墙与企鹅脚印

在第一轮圆形地图基础上，普通关卡半径从 120 缩至 100（矿山仍为 150）；冰块中心范围从 88 收紧至 76，中心出生区保留半径 16。各波数量、血量、种类、奖励和存档契约保持原有逻辑。

地面由圆形雪地材质绘制积雪斑驳、细颗粒和雪脊。围墙继续复用已使用的 GlacierDown 冰雪围墙纹理，沿圆周形成内壁、外壁和积雪顶沿，并设置 64 个边界碰撞段；旧长条边界和资源引用仍保留在停用分支中。

企鹅队伍走路时会左右交替留下三趾蹼足脚印。脚印按实际移动距离生成，静止不生成；停留约 1 秒后逐渐淡出，总寿命约 4 秒。暂停会停止脚印老化，传送不会拉出长线，换关和离开普通关卡会清理。脚印使用容量 192 的循环池，与冰块、金币等玩法对象池分开。

# 武器攻击特效 v2：查看与分色概念图

用户反馈攻击特效不好，要求查看主要图片素材，并允许非冰雪蓝配色。本轮交付设计预览，尚未接入或替换运行时资源。

## 当前问题的证据

`PenguinFullReskin.StyleParticle` 用 4 张通用图按路径分类，统一 startColor 和部分寿命颜色为蓝白，关闭贴图帧动画。包含 `Bullet` 的路径归入同一弹道图，`Bullet_FX` 命中节点也可能被该规则归入弹道。新图不能只按名称整体替换，否则会继续混淆枪口、飞行和命中用途。

只读 Editor 导出的 `original-emitter-inventory.json` 覆盖 65 套枪口、65 套弹道、65 套命中，共 638 个粒子发射器：442 Billboard、116 Stretch、80 Mesh，191 个发射器使用 3×3、10×10、2×2 或 6×3 贴图帧布局。Mesh 和动画贴图应按原渲染形式保留/单独适配，不能统一强塞一张静态光团。

## Git 核对

实际 `git ls-remote origin refs/heads/main` 返回 `be94578d6cf8c7b3d64722894d6f1b263ee5f6fd`，与本地 origin/main 一致。上述发射器引用的 14 张原始贴图全部在该提交树中，普通二进制 PNG（非 LFS 指针），Git blob 与当前文件逐字节相同；它们从 `7451a216f` 起纳入 Git 历史。因此这些原攻击贴图已经在远端历史里。当前 4 张通用新图及本轮概念图仍是本地未提交内容。本轮没有提交或推送。

具体路径、哈希和字节数见 `git-original-assets.json`；`reference/` 保存只读原始 blob 对照和当前四张新图的拼图。

## 建议方向

| 武器类型 | 主色 | 形态重点 |
| --- | --- | --- |
| 实弹 | 金橙 | 短闪、细尾迹、小火花 |
| 霰弹 | 铜橙 | 扇形枪口、单颗短尾弹丸；散射颗数仍由玩法发射 |
| 穿透 | 紫色 | 狭长尖锐弹道、斜向穿透火花 |
| 激光 | 青绿 | 细连续光束、紧凑电光命中；减少连串光圈 |
| 爆破 | 红橙 | 短火弹、紧凑圆润扩散 |
| 火箭 | 橙红 | 单个明亮弹头和收束尾焰、弧形爆炸波 |
| 爆裂狙击 | 金粉 | 细长高能弹道、强核心和少量弧形射线 |

`weapon-effects-review.jpg` 左大格用浅色战场背景，右小格用暗底与缩小视图，便于比较可读性。它是生成素材的裁切/缩放/排版，**不是游戏截图**。21 个仍是峰值阶段的概念图，不是完整帧动画；原生成图不满足精确统一格子尺寸，不能直接作为生产图集导入。`concept-crops.json` 是这张预览的裁切记录，不能当作 Unity Sprite slicing 规范。

两版图通过内置 image_gen 生成/编辑，提示词与来源在 `imagegen-manifest.json`，真实 RGBA alpha 已检查。`weapon-family-proposal.json` 记录 65 个原武器编号按原 GunType 分组的建议，不修改伤害、弹数、攻速或碰撞。

待确认外观后建议分批接入：先实弹/霰弹，再激光/穿透，最后爆破/火箭/爆裂狙击。接入时先按发射器用途分类、制作独立贴图/需要的动画帧，保留原发射与命中时机，并在实际游戏中核对密集射击、暂停和对象池重用。当前游戏、音效/BGM和玩家存档未由本轮修改；没有构建 APK，也没有以概念图声称运行效果已通过。

# 攻击特效：改为原版风格

用户针对上一张彩色攻击特效方案图要求「风格还是改成原版的」。本轮改的是该图的视觉方向，仍为图片设计预览，未修改游戏运行时资源。

`concept-r2.png` 使用内置 image_gen 编辑附图，并以原游戏实际贴图制作的 `../weapon-feedback-v2/reference/original-style-reference.png` 作为风格参考。保持七类武器、枪口/弹道/命中三列。改为简洁的白灰柔光蒙版、细光束、烟雾和扩散圈；移除上一版厚重彩色火焰、尖锐轮廓和花瓣装饰。颜色建议由原粒子颜色/梯度控制，不烘焙固定七色。

`concept-r1.png` 是中间稿，`concept-r2.png` 改善了外围噪点和光团之间的间距。两者均是 AI 重绘概念，不能称为原版逐像素资源。仍有少量边缘噪点，生产接入优先复用已有原贴图及其序列帧；如果使用重绘稿，需要逐张检查裁切、透明边缘、方向、图集帧布局和实际粒子材质效果，不能直接整张贴入所有发射器。

真实 alpha、图片尺寸与哈希记录在 `validation.json`。来源提示词在 `imagegen-manifest.json`。没有构建 APK、提交 Git或修改音效/BGM、场景、武器数值及玩家存档。

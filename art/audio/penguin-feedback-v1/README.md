# 企鹅主题音效与交互反馈 v1

本轮按用户选定的「清脆可爱：轻弹、水滴、冰晶」风格，已接入工作场景 `Assets/Recovery/Scenes/RecoveredClient.unity`。

- 17 类音效全部采用新编事件序列和程序合成；没有混入原音频。WAV 44.1kHz、16-bit，源母版保留双声道，Unity 导入为单声道 PCM。射击声为 105ms 的低音量短反馈，适合持续自动战斗。
- 场景 717 个 Button，启动后包含图鉴/语言选择等动态控件共 792 个 Button，均具有统一反馈。可见按钮按下缩到 92%，松开 160ms 回弹；全屏关闭背景保留完整点击范围及原颜色过渡。6 个自定义装备槽补上按压和选择反馈，不新增拖拽事件。
- 场景 72 个界面/弹窗入口，加 3 个动态界面，共 75 个反馈组件。内容 240ms 展开回弹；语言选择采用淡入，背景点击范围保持。原已有提示、加载角色和其他局部动画继续使用现有动画。
- 商业/业务提示声在同一点击分发帧优先，普通点击声延后到该帧 LateUpdate，避免双响。新交互反馈使用非缩放时间，静音仍由原设置管理。
- 音效类目：弹窗、按钮、生成、合成、升级、拒绝、重生、购买、射击、选中、进入、胜利、失败、取消选中、资源计数、强化成功、强化失败。背景音乐沿用现有音乐，本轮替换的是音效。

## 验证

每次运行的结果分别保留，不拼接成一次全套通过：

- `tests-second-final.json`：第一次有效专项 4/4，32.42 秒。
- `tests-final-status.json`：加入装备槽后的最终专项 5/5，38.87 秒；实际 EventSystem 输入覆盖 14 个主菜单、装备槽；验证暂停、取消、禁用、重开、静音和业务声优先。
- `regression-settings.json`：原有设置/声音去重/BGM 切换 2/2，0.8 秒。
- `regression-startup-status.json`：启动、自然自动移动射击、冷重载与存档保护 4/4，23.74 秒。
- `runtime-audit.json`：运行时 792/792 Button、6 个装备槽、75 个弹窗，场景缺脚本 0，只有 SFX/BGM 两个 AudioSource。
- `audio-validation.json`：17 WAV 可解码、有效且无削波，总文件 1,829,132 字节，峰值约 0.505；这些检查不代表主观音色验收。
- 编译过程中临时测试迭代器/变量名错误已修正；最早的 0 项测试报告不计为通过。

`ui-preview.wav` 顺序为按钮→弹窗→选中→取消→拒绝→升级→购买。`all-sfx-preview.wav` 按 17 类 enum 顺序试听。它们为合成素材拼接，**不是游戏实时录音**。`preview-final/` 为实际 Unity Editor GPU 动画预览。第一次 `preview/` 被自动签到弹窗干扰，只作过程证据，不称为设置预览。

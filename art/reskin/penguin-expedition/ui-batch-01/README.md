# 企鹅破冰探险：统一 UI 换肤

本批覆盖 RecoveredClient 的整个 Canvas，包括初始隐藏页面、长列表、弹窗，以及运行时克隆的武器图鉴、抽取说明和语言选择页面。使用 `PenguinUiTheme` 独立接入，已确认的角色、握枪翅膀、左右摇摆与射击动画保持原样。

## 设计与接入

- 冰蓝面板、深蓝描边、橙色购买与重点入口、珊瑚色不可支付提示、淡紫辅助层级；保留锁定、稀有度、资源种类和按钮状态的区分。
- 新增无围巾企鹅头像、雪花金币、冰屋商店、胜利、失败和离线休息插画。原素材与资源引用保留。
- 将重复纹理中的猫爪、暖色条纹换成雪花和冰蓝条纹；加载页换成企鹅。
- 在 Editor 中读取原边框中心透明度，区分命名不准确的空心边框，避免盖住奖励文字与按钮。
- 字体材质使用运行时副本。语言切换后仍应用主题描边；原字体资源不修改。
- 任务的树木、小猫等展示文案改成冰块、企鹅；原目录、目标数量、任务计数与奖励逻辑保留。
- 原武器、宠物、鱼、地图、核心和稀有度内容图标保持对应的功能含义；所有页面共享新的容器、按钮、字色与界面纹理。

关闭 `RecoveryForestClient` 上的 `PenguinUiTheme` 可以恢复本批原图、颜色、字体材质和展示文案。战斗换肤由单独的 `PenguinExpeditionTheme` 管理。

## 实际画面

`captures/` 为 Unity Editor 1080×1920 Game view GPU 截图，包含主界面、设置、商店、武器、皮肤、宠物、鱼、转生、任务、旅行、各模式入口、签到、胜负结算、加载和离线页。

预览使用独立临时存档，临时关闭自动签到弹窗、完成教程并显示所有菜单。结算、加载和离线页面为明确的界面展示场景，没有触发付款。它们不代表普通存档已经解锁全部功能或已领取截图中的奖励。`observation.json` 记录来源与范围。

`build-overview.py` 仅缩放、排列原始截图并添加页名；`ui-overview.png` 没有生成或重绘游戏画面。

另在 `captures/sizes/` 核对了 750×1334 和 1440×3200 的主界面与设置布局；截图保留原始尺寸，之后恢复 1080×1920。

## 验证与交付边界

每次测试单独保存在 `tests-*.json`，以各报告的完成状态为准，不把多轮执行合成一轮结果。`PenguinUiTests` 使用原 StandaloneInputModule 点击全部 14 个主菜单入口，并验证按钮绑定、RectTransform、点击目标、币值与动画对象没有因换肤而变化；另复查原有升级、设置和语言切换输入。

较早的语言测试出现过一次指针采样失败，无代码改动复跑通过；最初报告保留为 `tests-language-first.json`。最后补充主题文案时中断了一次升级测试，随后以完整的新执行结果复查。

已确认的动画与角色 8 个源文件及 `.meta` 使用 `penguin-actions/approved-assets.json` 保护校验。正常交付前清除预览存档覆盖并恢复测试动态生成的字体缓存；原报告截图恢复，新测试截图归档到本目录。

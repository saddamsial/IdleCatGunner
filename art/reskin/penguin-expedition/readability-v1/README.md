# UI 可读性调整 · 2026-10-13

保留已认可的企鹅、冰雪素材与整体风格，调整各页面的进度、标题、正文和状态颜色。修改前本地备份提交：`274b03077225c82fb4ccf0577e6d6f7d70cba2a3`。本轮没有推送远端。

## 修改

- 经验条 `Reward/EXP_Slider/Fill`、奖励轨道 `Reward/Scroll View/Viewport/Content/Slider` 及任务、探险、挑战等进度条采用浅冰色轨道与深蓝填充；保留真实比例、截断方式和数值。
- 降低填充内条纹的不透明度。显式包含初始隐藏的父组件，确保首次打开任务页也有清楚的填充和橙色领取按钮。
- 欢迎回来、结算、商店、签到等标题底板改为较深蓝色，标题采用浅色字；减弱少数礼包的荧光绿/青色 UI 光晕。
- 正文采用柔和深蓝，次要/禁用文字采用带蓝色的灰阶，动态价格与状态颜色同步处理。警告色仅用于明确的亮红色来源，旧棕色正文归入深蓝。
- 文字处理从 Canvas 渲染回调移到 `LateUpdate`，每秒任务计时只刷新倒计时与跨日模型检查。进度/领取由模型事件刷新，避免每秒重新改写任务行。
- 任务页通行证按钮改为左边缘锚点，保持普通竖屏位置，避免平板左侧裁切；关闭主题会恢复原锚点。

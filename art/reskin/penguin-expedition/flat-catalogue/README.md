# 平涂手绘素材

以用户认可的 16 图标参考图为画风依据：粗深色描边、圆润轮廓、清楚色块和少量明暗。风格参考已加入现有 `unity-visual-reskin` 技能；主题和配色仍按具体游戏选择。

## 本批资源

65 把枪、13 种鱼、13 个宠物、9 个普通 Boss、5 个团队 Boss、20 个怪物、16 张钻石/道具图、4 张攻击特效图；后续增加 20 张冰块/场景小物件/奖励图和 4 张背景。共 169 张 PNG，其中 165 张透明图、4 张不透明背景。金币使用此前同画风的 `PenguinExtras/flat-ui-coin.png`，本批另提供金币堆与奖励袋。原生光圈保留用户要求的原版图集、网格和动画。

`prompts.json` 记录生成提示词和原始文件；`raw/` 保留完整图集，额外草稿格子没有安装。`cut-atlases.py` 仅提取轮廓、保留 alpha、裁切和缩放；`assets.json` 记录切片，`manifest.json` 记录文件哈希。`catalogue-preview.png` 和各系列 `*-sheet.png` 为素材排版预览，并非游戏截图。

## 接入

通过 `AgentScripts/InstallPenguinFlatCatalogue.cs` 和 Unity Editor API 安装。原始资源保留；新 Sprite 使用原资源的尺寸、边界、pivot 和 border；原装备编号、鱼/宠物选择、Boss 阶段、购买回调和存档流程继续使用原控制器。文本内嵌货币图同步到新的 TMP 图集，保留 glyph 编号与排版指标。

本批保护已经认可的企鹅身体、骨骼摆动、眨眼、握枪连接；保留其他聊天完成的地图、镜头与脚印修改。测试与预览使用隔离存档。

安装结果写入 `bindings.json`；实际游戏画面与验证结果在完成后另外保存。预览图本身不证明游戏内接入或真机表现。

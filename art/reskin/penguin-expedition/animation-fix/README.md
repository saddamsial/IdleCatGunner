# 企鹅主角动作修复

本目录记录早期骨骼适配。用户后续要求企鹅左右摇摆及专属射击动作，并要求修正枪柄处的黑色手掌；最新实现和运行画面见 `../penguin-actions/`。

问题：第一批企鹅是单张 Sprite；每帧固定摄像机朝向、大小和地面位置后，原猫咪 SpriteSkin 的身体变形没有传递到新企鹅。枪械虽然仍使用原骨骼，但身体静止。

修复：保留已认可的无围巾企鹅贴图、大小、枪械层级、冰块和背景。增加 `PenguinBoneMotion`，以有固定 UV 的 24×28 网格显示同一贴图；每帧读取现有 Animator 骨骼的姿态差异，使贴图随身体、脚和鳍变形。角色移动、攻击和原 Animator 控制器继续使用现有逻辑。

动作映射：

| 原动画来源 | 企鹅动作 |
|---|---|
| bone_1 的位置、旋转、缩放 | 身体起伏和行走节奏 |
| bone_4 / bone_5 的位置与旋转 | 左右脚迈步 |
| bone_8 / bone_9 的旋转 | 左右鳍摆动 |
| bone_2 的尾巴旋转 | 轻微身体摆动 |
| Face_Pivot_trans 的瞄准旋转 | 头部随瞄准轻微转动 |

这是为新美术做的动作适配，不是恢复作者的企鹅骨骼，也不代表所有 UI 角色、加载/结算动画已换为企鹅。没有新增围巾、耳朵、尾巴、裂纹或散落效果。

`original-animation.json` 是当前主角的原控制器、骨骼与动画轨道清单。`tests-before-fix.json` 记录静态版本未通过动作检查；`tests-final.json` 是本轮最终 PlayMode 结果。测试用独立存档，检查待机和行走确实改变可见网格、暂停冻结、自然战斗、奖励只发一次以及主题回退。

`captures/natural-*` 来自原自动战斗；`idle-*` / `walk-*` 是在同一个实际 Game view 中，用原 Animator 的 Walk 标志隔离演示两种动作的诊断画面，临时暂停战斗后会恢复。它们不是生成的动画帧。验证范围为 Unity Editor，尚未做真机验收。

# 企鹅破冰探险：全目录换肤

延续已认可的企鹅体型、左右摆动和射击后坐动作。不加围巾，不增加冰块碎裂或散落效果。

## 本批内容

- 25 套企鹅皮肤；主角、两名队友和团战助手使用同一个已认可的动态网格。独立表情层负责眨眼、短暂开口和射击时的喙变化。
- 65 把极地武器，13 种鱼、13 个宠物展示素材，9 个普通 Boss、5 个团战 Boss、20 个狩猎敌人。世界宠物和 19 个探险宠物预览节点都替换，保留原跟随与派遣逻辑。
- 黑曜石、紫晶、白晶、琥珀货币；5 套 TMP 内嵌图标图集保留原字形编号、指标和排版。
- 攻击力、攻速、暴击伤害、暴击率、移动速度、图鉴、矿山票和自动采钻图标；所有小猪图标改为企鹅晶矿机；其余功能、导航和礼包图标同步替换。
- 每周商店新插画；探险地图、冰下鱼池和 Boss/团战场地使用极地素材。
- 冰蓝弹道、紫蓝能量环、命中星光和寒气。沿用原粒子数量、寿命、发射与命中流程；无冰块碎片。飘字改为海军蓝描边，钱币、钻石前缀也使用新图形。

## 实现与保护

`PenguinFullReskin` 在原控制器初始化后更新实际 Sprite 引用和目录，不重编号或修改物品价格、伤害、攻速、掉落、存档、按钮回调或碰撞体。新图片通过 Unity AssetDatabase 创建独立资产，不覆盖原图片或手工编辑场景 YAML。364 条精确资源绑定记录在 `bindings.json`，215 张来源图记录在 `assets.json`；生成来源及提示词位于 `manifest.json` 和 `raw/`。

角色的摆动网格、原主题脚本和基础企鹅图共 8 个已认可文件通过 `approved-assets.json` 哈希保护。队友新增独立锚点先于动态网格更新，防止手臂跟随延迟。新表情和全部视觉替换可撤销；原骨骼、Spine 动画和 Boss 动画事件继续执行。

回退本批可在 EditMode 禁用 `PenguinFullReskin`，继续使用上一批冰蓝 UI 和基础企鹅动作；原资产保留。UI 脚本的 Git HEAD 副本保存在 `backup/`。已有音效/BGM 工作不由此批修改。

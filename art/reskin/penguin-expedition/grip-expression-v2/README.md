# 企鹅短翅膀、表情与胜利动作

本批按用户反馈，将身体图层里靠近镜头的翅膀移除，用独立、短而圆润的翅膀握枪。枪的显示位置靠近翅膀，保持原装备组件、枪口 Transform、弹道、碰撞、攻击数值和存档逻辑。25 个皮肤编号保持原顺序，加入背包、救生衣、围裙、制服等身上装饰与不同表情；无围巾。

`raw/` 与 `prompts.json` 保留图像生成来源；`prepare-actions.py` 只裁切、缩放和提取表情区域，输出 25 个身体图层与 1 个独立翅膀。旧版草稿不安装。`skins-body-contact.png` 是身体图层排版，不是实际游戏截图；游戏会另外叠加翅膀和枪。

`InstallPenguinActionsV2.cs` 通过 Editor API 保持原资源边界与 pivot，保存皮肤映射、眼睛坐标和握枪配置。原企鹅 PNG、骨骼资源和 GUID 保留；用户明确授权修改原 `PenguinBoneMotion.cs`，旧版本在 `backup/`，因此之前“8 个文件全部不变”的保护结论不再适用于本批。

射击时表情随原生后坐力变化；原生通关 UI 出现时执行三次视觉小跳和开心表情，不重复调用奖励。胜利全程保留枪与圆厚翅膀，使用起跳和落地速度平缓的三跳曲线，并渐变开心表情。跳跃只变形显示网格，不移动 Rigidbody 或碰撞体。原关卡切换时序不变。

## 攻击特效决定

用户再次明确拒绝 `PenguinFlatCatalogue/effects-00.png` 和 `effects-02.png` 作为子弹与命中效果，偏好原版高级武器 `ToonCircle02_3x3.png` 动态图集。本批启用 `PreserveOriginalAttackEffects`，枪口、子弹与命中粒子恢复原素材、渲染和动画模块；`PreserveOriginalRingStyle` 同时保持原环形图集。静态图保留为未使用草稿，不删除原始资源。

原版加法粒子会沿轨迹叠加大量发射点；直接用粗描边静态图替换，会堆出密集黑点和彩色纹理。最终方案移除这类攻击替换，使用原动画表现。

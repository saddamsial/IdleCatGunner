# 企鹅专属走路与射击动画

当前版本按用户要求设计企鹅动作，替代早期的猫咪骨骼动作适配。保留无围巾造型、冰块和冰雪背景，不增加裂纹或冰屑散落。

| 状态 | 设计 |
|---|---|
| 待机 | 很轻的呼吸起伏，双脚落地 |
| 走路 | 身体左右摆约 7.5 度，双脚交替抬起，鳍随身体保持平衡；速度越快步频略增，停止时约 0.14 秒回稳 |
| 射击 | 实际开枪后身体后仰约 8 度，前 0.045 秒达到峰值，约 0.24 秒回正；保留原枪械、枪口和弹丸效果 |
| 握枪 | 隐藏原猫咪的圆形手掌和手掌描边，以深灰短鳍从身体连到枪柄，随瞄准与枪械后坐力移动 |

身体动作使用独立的 Penguin 视觉网格，读取原移动控制器的 Walk 意图和实际速度；它不再依赖猫咪迈步、耳朵或尾巴的动作曲线。射击响应来自原成功开枪后触发的 `Rebound_bounce`，空池或没有开枪不会自行播放射击动作。视觉组件不改变射速、伤害、目标碰撞、奖励或存档。

`tests-final.json` 保存本版单次 PlayMode 检查结果，覆盖自然战斗与短鳍显示、主题恢复、左右摆动及暂停、实际开枪后坐力只触发一次并回正。

`captures/natural-*` 是原自动战斗 GPU 帧；`idle-*`、`walk-*`、`shoot-*` 是同一 Game view 的隔离动作演示。走路演示控制 Walk 意图，射击演示调用实际 Attack，在临时冻结战斗的独立存档中录制，不给予合成击中奖励。录制结束恢复状态；普通 Play 不保留预览存档覆盖。

截图、动画 GIF 和逐帧检查图均来自 Unity Editor 实际画面，没有用图像生成工具制造动作帧。尚未做 APK 或真机帧率验收。前一版 `animation-fix/` 中的骨骼映射与录制仅供历史对比，本目录为最新方向。
